# KeeperHub reference design notes

The live Lovable hostname could not be loaded in the sandbox because the host returned an SSL protocol mismatch. The provided GitHub repository was accessible and confirms the intended product language: KGB is a DCA execution and reliability dashboard with a dashboard shell, execution activity area chart, wallet status card, recent activity, history, configuration, audit trail, and settings routes.

The reference stylesheet uses a dark navy/blue palette with high-contrast foreground text, green primary/status color around hue 152, rounded cards, subtle borders, tight dashboard spacing, tabbed/route navigation, and utility polish such as antialiasing, accessible focus rings, small scrollbars, and short entrance animations. The reference dashboard uses a 3-column metric/activity layout, a larger execution chart, a wallet status card, and recent activity rows with compact badges and transaction links.

The current KGB app already has a dark grid and cyan action treatment, but should be moved closer to the reference by adding the green reliability signal, route-like navigation state, tighter card hierarchy, dark navy tokens, and small responsive polish while retaining the current tRPC-backed data and existing authentication flow.
