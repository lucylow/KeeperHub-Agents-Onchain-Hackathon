# Wallet Funding Guide for KGB Agent

To execute DCA transactions on Base mainnet or testnet, your agent's wallet needs sufficient funds for both the swap and gas.

## 💰 Funding Requirements

| Network | Asset | Minimum Recommended | Purpose |
| :--- | :--- | :--- | :--- |
| **Base Mainnet** | USDC | $10.00 | Swap Input |
| **Base Mainnet** | ETH | $3.00 (0.001 ETH) | Gas Fees |
| **Base Sepolia** | USDC | 10.00 | Test Swaps |
| **Base Sepolia** | ETH | 0.01 | Test Gas |

## 🛠 How to Fund

### 1. Mainnet Funding
- **Coinbase Onramp**: The easiest way to fund your Turnkey-managed organization wallet.
- **Direct Transfer**: Send USDC and ETH to the wallet address displayed in your KeeperHub dashboard.

### 2. Testnet (Sepolia) Funding
- **Base Sepolia Faucet**: [https://www.coinbase.com/faucets/base-ethereum-sepolia-faucet](https://www.coinbase.com/faucets/base-ethereum-sepolia-faucet)
- **USDC Faucet**: Use the KeeperHub dashboard testnet faucet if available.

## ⛽ Gas Sponsorship
KeeperHub provides **gas sponsorship** for new builders. Check your `WalletStatus` in the dashboard to see if your account is currently eligible for sponsored transactions.
